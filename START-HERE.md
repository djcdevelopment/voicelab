# First five minutes

1. Extract ZIP contents directly into `/work/subtitle` (see README.md). A zip without an enclosing root directory is intentional.
2. Run `cd /work/subtitle && ./scripts/smoke.sh`.
3. Give your coding agent the entire text of `prompts/BUILDER-PROMPT.md`.
4. Let the agent run read-only discovery, get one actual local English voice producing WAV, and propose Intel XPU research gates.
5. Bring the `docs/FRONTIER-PLAN.md`, `docs/HANDOFF.md`, and first receipt back for review before expanding scope.

This starter is a runnable diagnostic/prototyping harness, not a full streaming integration.
